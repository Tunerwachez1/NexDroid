# Автоматический текстовый ввод

Когда Android сообщает о текстовом редакторе текущей игры, NexDroid приостанавливает игровые привязки и передаёт клавиатуру Android. При завершении редактирования управление возвращается. Видимость экранной клавиатуры не используется как признак редактора.

В боковой панели «Автоввод текста» включает/выключает автоматику для текущего сохранённого игрового профиля. В `cont_<package>.json` этому соответствует `"auto_text": true` (значение по умолчанию для старых профилей). F8 или переназначенная команда текстового ввода временно переопределяет режим до следующего изменения состояния редактора.

При переключении освобождаются активные игровые касания и клавиши. Уже удерживаемая физическая клавиша не превращается в новое нажатие до отпускания. При входе в редактор освобождается mouse capture; обратно он запрашивается, только если ранее был включён, окно осталось активным и редактор управления/настройки закрыты. Уход в другое окно отменяет отложенное восстановление захвата.

## Архитектура

Android-компонент `HardwareIme` получает `onStartInput`/`onFinishInput`, учитывает `EditorInfo.inputType` и наличие `InputConnection`. Start с TYPE_NULL также выключает текстовый режим: в Standoff `mInputStarted` может оставаться true после закрытия чата.

`EditorFocus` передаёт только `{package, active}` по постоянному Unix socket `/data/local/tmp/waydroid-hardware-keyboard/focus.sock`. Rust читает этот socket из общей директории Waydroid data, проверяет UID отправителя через SO_PEERCRED и ограничивает размер сообщения 512 байт. После записи состояния в память Rust подтверждает получение; IME ожидает ACK с ограниченным временем. Отдельный Android worker восстанавливает соединение и каждые 500 мс повторяет текущий snapshot. Изменения фокуса отправляются сразу, без ожидания heartbeat.

Обработчик Rust проверяет snapshot памяти перед маршрутизацией клавиши. В горячем пути нет shell, dumpsys, ADB или чтения сокета. Текст и пароли не передаются. При разрыве остаётся последний известный режим, доступен ручной F8. Для работы необходима обновлённая HardwareIme из `android/desktop`; единый установщик устанавливает и Rust UI, и APK.

## Проверка

Открыть чат → сразу напечатать текст, включая WASD/Shift/Caps/RU/EN → закрыть чат → проверить движение. Повторить с зажатой W, захватом камеры, Alt+Tab и F8 override. Игры, не создающие Android InputConnection, требуют ручного переключения; автоматическое обнаружение таких собственных редакторов не гарантируется.
