# NexDroid fork notice

NexDroid is a modified fork of
[Liwinux](https://github.com/Liwinux-Project/liwinux), originally developed by
the Liwinux contributors. The upstream Git history is intentionally preserved
so individual authorship remains traceable.

The NexDroid beta adds and changes the desktop interface, embedded Android
window, input forwarding, per-game JSON control profiles, control editor,
Waydroid lifecycle handling, display integration, diagnostics, branding and
installation shortcuts.

NexDroid is not an official Liwinux release and the upstream project is not
responsible for NexDroid-specific changes or support.
